# React + Vite

# 🚀 Landing Page - JH Informática

Este projeto é uma landing page de alta conversão construída com as tecnologias modernas do ecossistema JavaScript: **Vite**, **React** e **Tailwind CSS**. O foco do design é em um tema escuro (Dark Mode) com uma paleta de cores vibrantes (rosa e violeta) para destacar a Proposta de Valor e os CTAs (Chamadas para Ação).

## ✨ Funcionalidades Principais

* **Estrutura Moderna:** Utiliza React para componentes reutilizáveis e gerenciamento eficiente da UI.
* **Performance:** Inicialização e *Hot Reloading* rápidos graças ao Vite.
* **Estilização Rápida:** Tailwind CSS para estilização utilitária, permitindo um desenvolvimento de design ágil e responsivo.
* **Design Otimizado:** Layout focado em conversão, incluindo:
  * Barra de Anúncio de Urgência (`PromoBar`).
  * Seção Hero com Gradiente de Título (`HeroSection`).
  * Gatilhos de Confiança e Prova Social (`KeyMetrics`, `IncludedPrograms`).
  * Botão Flutuante de Suporte via WhatsApp (`WhatsAppFAB`).
* **Responsividade:** Design adaptável para funcionar perfeitamente em dispositivos móveis e desktops.

## 🛠️ Tecnologias Utilizadas


| Tecnologia            | Descrição                                                        |
